# Identidad visual de Tentación Sana

## Activo oficial

- Usar `assets/logo-oficial-tentacion-sana.png` como archivo maestro del logotipo.
- Mantener la composición completa: texto blanco inclinado **TENTACIÓN SANA**, contorno oscuro y hojas verdes.
- Conservar siempre la proporción original y la transparencia del PNG.
- No reconstruir el logotipo usando una fuente similar ni aplicar cambios de color, sombras, contornos o efectos no aprobados.

## Aplicación en el sistema

- Mostrar el logotipo completo en la cabecera del sitio público, portada, catálogo, inicio de sesión y panel interno.
- Priorizar fondos oscuros o suficientemente contrastantes para que el texto blanco y las hojas verdes mantengan legibilidad.
- En diseño responsive (adaptable), reducir el logotipo proporcionalmente mediante `object-fit: contain`; nunca estirarlo ni cortarlo para llenar un espacio.
- Incluir texto alternativo accesible: `Tentación Sana`.
- Preparar versiones optimizadas para web conservando el archivo maestro. Usar WebP o AVIF para rendimiento solo cuando la conversión mantenga transparencia, nitidez y apariencia visual.

## Favicon e iconos reducidos

- Usar una versión secundaria basada únicamente en las hojas verdes cuando el espacio no permita leer el logotipo completo, por ejemplo favicon, icono de aplicación o avatar pequeño.
- La versión reducida no reemplaza el logotipo oficial en encabezados, portadas, documentos o piezas comerciales.
- No improvisar otro símbolo ni usar iniciales como sustituto sin aprobación expresa.

## Usos prohibidos

- No cambiar la tipografía.
- No modificar los colores del texto o de las hojas.
- No comprimir, ensanchar, inclinar adicionalmente ni rotar.
- No separar las hojas del nombre salvo para la versión reducida autorizada.
- No colocarlo sobre fondos que oculten su contorno o reduzcan su contraste.
- No añadir eslóganes dentro del logotipo.
